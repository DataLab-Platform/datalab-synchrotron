Test files of the XDI library, used to validate the XDI reader.

Source: XAS-Data-Interchange, https://github.com/XraySpectroscopy/XAS-Data-Interchange

The files are unchanged. Their SHA-256 are listed in SHA256SUMS and checked by
the tests (tests/validation/test_xdi_corpus.py). BadFiles.txt describes the
error of each invalid file and how the XDI library reads it.
