Extracts of real SPEC files used to validate the SPEC reader.

The files are generated by tests/validation/make_spec_corpus.py from sources at
pinned commits; the scans, points kept and SHA-256 of the sources and of the
files are listed in tests/support/spec_corpus.py.

Sources:

- spec2nexus, https://github.com/prjemian/spec2nexus
  Commit: 7d315b23463631ae07c98a07d2abc0034e665431
  Folders: spec2nexus/data, spec2nexus/tests/data
  License: CC BY 4.0, see LICENSE-spec2nexus.txt
  Changes: issue216_scan1.spec, user6idd.dat and twoc.dat are unchanged. The
  other files are extracts: the scans listed in spec_corpus.py, each preceded by
  the file header that applies to it, the scans of mca_spectra_example.dat and
  startup_1.spec being limited to their first 3 points.
  mca_spectra_example_scan1.spec      <- data/mca_spectra_example.dat
  33id_spec_mesh_escan.spec           <- data/33id_spec.dat
  20220311-161530_scan2.spec          <- data/20220311-161530.dat
  05_02_test_none.spec                <- data/05_02_test.dat
  spec_from_spock_scan1.spec          <- data/spec_from_spock.spc
  startup_1_scan16.spec               <- data/startup_1.spec
  CdSe_scan92.spec                    <- data/CdSe
